# BGi Desktop：桌面底部 UI 資訊架構與操作優先序

> 日期：2026-08-10（Asia/Taipei）
> 狀態：獨立桌面 UI 規格；以文字暫代即可實作與驗收。
> 依據：桌面常駐、任務生命週期、文字暫代 UI、背景／掛件不變性與 UI 視覺階層研究。
> 非範圍：不改主規格、Godot 或素材；不決定黑市內容、經濟數值、解鎖門檻或美術尺寸，均維持 `[PLACEHOLDER]`。

## 1. 桌面底部容器規則

- 遊戲容器固定於 Windows 可用工作區底部，工作列外；任何主入口、次級面板、對話框與通知均不得覆蓋 Windows 工作列。
- 未繪製 UI 區域保持透明且不攔截桌面操作；只有按鈕、列表、卡片與開啟中的面板接收輸入。
- 標準與緊湊配置皆保留「任務／收取」常駐區；其他內容可收合，但可收取與派遣中倒數不可被隱藏。
- 只有一個次級面板可同時開啟。開啟後不覆蓋任務常駐區；若可用高度不足，縮減場景畫布與次級面板內容，任務區維持優先。
- 所有入口以短標籤＋icon／文字符號呈現；無美術時，以固定文字鍵與簡單狀態符號替代，不能因此取消任何操作。

## 2. 標準配置與區域責任

```text
Windows 可用工作區（工作列上方）
┌──────────┬──────────────────────────────┬──────────────────────┐
│ 主入口列  │ 場景／次級面板                │ 任務與收取常駐區       │
│ 地盤      │ 預設：勢力場景                │ H1：可收取／派遣確認   │
│ 黑市      │ 開啟入口後：對應次級面板       │ H2：倒數、隊伍、刷新   │
│ 角色      │ 收藏展示內容僅在此區呈現       │ 任務卡與錯誤訊息       │
│ 收藏      │ 不承載任務／地盤數值           │                      │
│ 設定      │                              │                      │
└──────────┴──────────────────────────────┴──────────────────────┘
```

| 區域 | 常駐內容 | 可收合內容 | 禁止事項 |
| --- | --- | --- | --- |
| 主入口列 | 地盤、黑市、角色、收藏、設定五個入口；每項可帶狀態角標。 | 入口文字可在緊湊配置收為 icon＋tooltip。 | 不放任務倒數、收取按鈕或長篇詳細資料。 |
| 場景／次級面板 | 預設顯示完整背景、前景掛件、場景物件／套件、人物狀態與長期成長摘要。 | 地盤細節、黑市、角色列表、收藏庫、設定。 | 不把任務卡烘焙入背景；背景切換不得改變掛件資料，套件切換不得移除既有所有權。 |
| 任務與收取常駐區 | H1 行動、目前派遣、可收取、任務列表摘要、刷新額度。 | 任務詞條、報酬機率詳情、已收取歷史。 | 不被次級面板、背景提示或黑市內容遮擋。 |

## 3. 主入口與次級面板映射

| 主入口 | 入口顯示與角標 | 次級面板內容 | 與任務面板的關係 | 未解鎖／未定處理 |
| --- | --- | --- | --- | --- |
| 地盤 | `ui.nav.territory`＝「地盤」；顯示目前地盤 ID、首次觸及或可查看進度角標。 | 地盤進度、探索收藏數、環境布置擁有數、已觸及地盤清單。 | 任務收取引發地盤變化時，先完成收取結果，再更新此入口角標；不搶走收取面板。 | 未觸及地盤顯示鎖定與條件 `[PLACEHOLDER]`。 |
| 黑市 | `ui.nav.market`＝「黑市」；僅在有新項目／可查看時顯示角標。 | 後續交易、物品或交換入口；第一版只可展示文字暫代與鎖定狀態。 | 黑市不得改寫進行中任務、結果或收據；開啟時任務常駐區仍可收取。 | 內容、價格、貨幣與解鎖條件均為 `[PLACEHOLDER]`；不提供空白或假交易按鈕。 |
| 角色 | `ui.nav.crew`＝「角色」；顯示可用／派遣中人數，待收取以任務角標呈現。 | 人物列表、狀態、所屬進行中任務、首次觸及解鎖的新人物提示。 | 派遣選擇從任務卡開啟；已完成待收取的原派遣人物可再選。角色面板不能取消任務。 | 未解鎖人物可見但鎖定，顯示條件 `[PLACEHOLDER]`。 |
| 收藏 | `ui.nav.collection`＝「收藏」；顯示新收藏或未處理完整背景提示角標。 | 完整背景庫、前景掛件庫、場景物件／套件與純收藏清單、目前背景與已啟用套件、動態效果偏好入口。 | 背景套用提示排在收取／人物解鎖提示之後；完整背景、前景掛件、場景物件與場景套件均不得承載任務數值。 | 未擁有項目顯示鎖定與條件 `[PLACEHOLDER]`；場景物件 placement UX 為尚待決策；無素材時顯示文字 ID 與狀態。 |
| 設定 | `ui.nav.settings`＝「設定」；通常無角標。 | 置頂偏好、標準／緊湊配置、減少動態、桌面常駐開關與存檔診斷入口。 | 設定開啟不得隱藏可收取或到期提示；存檔錯誤以 H1 狀態顯示並可從此查看診斷。 | Steam Cloud、帳號與跨裝置同步不列第一版操作；其項目顯示「後續整合」。 |

## 4. 任務面板與全域操作優先序

任務面板是唯一提供派遣、收取與刷新操作的區域。任何次級面板都只能顯示任務相關摘要或跳轉，不能複製一組會競爭狀態的派遣／收取按鈕。

| 優先 | 狀態或事件 | 主顯示位置 | 主要動作 | 其餘入口行為 |
| ---: | --- | --- | --- | --- |
| H1-0 | 無法安全讀取存檔／`recovery_hold` | 任務區頂部的錯誤卡。 | 重試讀取／查看錯誤碼。 | 停止會改寫未驗證資料的動作；可查看已驗證的唯讀內容。 |
| H1-1 | `completed_pending_claim` | 任務區頂部可收取卡。 | 收取成果。 | 地盤、角色、收藏只以角標提示；不得覆蓋收取卡。 |
| H1-2 | 派遣確認 | 任務區內派遣確認卡。 | 確認派遣。 | 角色面板可查看，但選人與確認只在任務區完成。 |
| H2-1 | `active` 任務 | 任務區常駐任務卡。 | 查看任務。 | 角色入口更新忙碌數；不得提供取消。 |
| H2-2 | 刷新額度可用 | 任務區刷新列。 | 刷新未接受任務。 | 不搶占可收取或派遣確認。 |
| H3 | 首次觸及、人物解鎖、新收藏／背景提示 | 對應主入口角標與順序提示佇列。 | 查看細節／確認背景套用。 | 在收取交易完成後依序顯示；同一時間只開一個確認視窗。 |
| H4 | 報酬機率、詞條、黑市詳情、歷史紀錄 | 次級面板或任務細節收合區。 | 查看／關閉。 | 不遮擋 H1 或 H2。 |

提示順序固定為：存檔安全錯誤 → 可收取 → 派遣確認 → 人物解鎖 → 背景套用確認 → 新收藏／其他角標。背景套用採「確認套用／暫不更換」；暫不更換仍保留在收藏庫，且不改寫掛件位置、層級或效果。

## 5. 緊湊配置的降級規則

| 元件 | 標準配置 | 緊湊配置 | 不得降級的內容 |
| --- | --- | --- | --- |
| 主入口列 | icon＋短標籤的垂直列。 | 只顯示 icon／文字符號與 tooltip；仍保留狀態角標。 | 五個入口皆可到達。 |
| 場景／次級面板 | 場景與開啟的次級面板可完整並列。 | 場景縮為摘要列；次級面板以單頁覆蓋場景區，不覆蓋任務區。 | 背景／掛件資料不因切換或縮放而改寫。 |
| 任務區 | 顯示任務卡、列表與刷新。 | 顯示 H1 卡、目前活動任務、刷新額度與「查看任務列表」。 | 可收取按鈕、派遣確認、倒數、錯誤原因。 |
| 補充資料 | 任務詞條、機率、歷史、收藏細節。 | 收合於「查看詳情」。 | 保底與額外報酬欄位仍可從任務卡進入。 |

## 6. 無美術驗收

1. 在僅有文字、按鈕與狀態符號的情況下，可從五個主入口進入對應次級面板；每個未解鎖入口都有文字條件，沒有空白頁。
2. 派遣、倒數、可收取、刷新與存檔錯誤在標準與緊湊配置均可完成或閱讀；任務常駐區未被任何次級面板遮擋。
3. 地盤首次觸及、人物解鎖、背景解鎖同時發生時，先完成收取，再依序看見人物解鎖與背景確認；掛件位置、層級與動態設定不變，場景套件既有所有權不變。
4. 將容器定位在 Windows 可用工作區底部時，工作列仍可點擊；未繪製區域點擊能穿透至桌面。
5. 關閉動態效果或無背景／掛件素材時，所有主入口、任務操作與文字提示均可用。
