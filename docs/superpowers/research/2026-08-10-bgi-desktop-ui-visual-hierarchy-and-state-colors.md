# BGi Desktop：UI 視覺階層與狀態色規範

> 日期：2026-08-10（Asia/Taipei）
> 狀態：研究規格。未導入素材、未修改 Godot 或 Git。
> 目標：讓工作列上方的低高度桌面介面維持任務可讀性，並讓圖示、文字與狀態色符合相同語意。

## 1. 視覺階層

| 層級 | 使用對象 | 範例 | 呈現規則 |
| --- | --- | --- | --- |
| H1 | 立即可行動事件 | 可收取任務、背景套用確認、任務派遣確認 | 使用明確按鈕、icon、短文字與高對比邊框；同一時間只凸顯最重要的一件。 |
| H2 | 當前進度與時間 | 任務倒數、派遣人數、地盤階段、刷新額度 | 數字與狀態 icon 並列；倒數使用等寬數字，避免版面跳動。 |
| H3 | 長期成長入口 | 地盤、布置、黑市、角色、收藏、背景庫、掛件庫 | 24px 或 32px icon 加短標籤；未解鎖可見但不可與可用操作混淆。 |
| H4 | 補充資訊 | 保底／額外報酬說明、機率、詞條、提示 | 預設收合或置於第二層面板；不可遮擋 H1 或 H2。 |
| H5 | 裝飾回饋 | 背景霧層、招牌光、收藏漂浮 | 低對比、低頻；不能降低文字、按鈕或狀態 icon 可讀性。 |

## 2. 色彩 token 與非色彩訊號

| token | 色值 | 語意 | 必要非色彩訊號 |
| --- | --- | --- |
| `surface.base` | `#0C1018` | 主要深色底 | 面板層級、間距與框線。 |
| `surface.raised` | `#141C28` | 浮起面板、任務卡 | 陰影或 1px 邊線。 |
| `line.gold` | `#B9934D` | 已選取、主題框線、稀有提示 | 角標、描邊或圖示形狀，不能只靠金色。 |
| `state.available` | `#5CCB8A` | 可派遣、可刷新、可放置 | 勾選、上箭頭或實心狀態點。 |
| `state.active` | `#73A7FF` | 派遣中、倒數進行 | 計時器或移動方向符號。 |
| `state.claimable` | `#F1C75B` | 可收取、待確認套用 | 收納盤、星芒或明確 `收取` 文字。 |
| `state.locked` | `#7E8794` | 未解鎖、條件不足 | 鎖頭與低對比文字。 |
| `state.warning` | `#C7746B` | 不可執行、資料異常、操作需注意 | 驚嘆符號與原因文字。 |
| `text.primary` | `#D7DDE7` | 主文字 | 字級與權重。 |
| `text.secondary` | `#AEB8C7` | 補充文字 | 位置較次要，仍需保有可讀對比。 |

所有狀態必須同時使用色彩與圖示／文字。可收取不得只以金色閃爍表示；鎖定不得只降低透明度；警示不得只使用紅色。

## 3. icon 狀態處理

| 狀態 | icon 外觀 | 文字／互動 | 動態規則 |
| --- | --- | --- | --- |
| 可用 | 正常描邊或雙色 icon，套用 `state.available` | 可點擊，顯示主要行動文字。 | 可有一次性低幅度入場提示。 |
| 派遣中 | `state.active` 加計時器或隊伍角標 | 顯示倒數與已派遣人數；派遣按鈕改為查看或中止。 | 僅局部低頻脈動，不可影響倒數數值。 |
| 可收取 | `state.claimable` 加收納盤或星芒 | `收取` 為明確可點擊動作。 | 可低頻光暈；減少動態時保持靜態金色與 icon。 |
| 鎖定 | `state.locked`、鎖頭角標 | 顯示解鎖條件，不可觸發空白行為。 | 不播放提示動畫。 |
| 不可執行 | `state.warning`、驚嘆或禁止符號 | 顯示原因，例如人數不足、無刷新額度。 | 不連續閃爍，避免誤認成可收取。 |
| 已完成／已收取 | 一般文字與完成勾選 | 供歷史或列表辨識，不占用 H1。 | 無常駐動畫。 |

## 4. 桌面低高度配置規範

| 區域 | 優先顯示 | 可收合內容 | 禁止事項 |
| --- | --- | --- | --- |
| 左側：地盤／布置 | 目前地盤階段、布置入口、可見長期成長角標 | 詳細地盤條件、收藏清單 | 不將任務倒數藏在此處。 |
| 中央：場景畫布 | 背景主題、可拖放掛件、小弟狀態 token、可收取訊號 | 背景庫、掛件庫、效果偏好 | 不把文字任務卡烘焙到背景。 |
| 右側：任務／收取 | 任務卡、倒數、派遣人數、保底／額外、收取、刷新 | 詞條、機率詳情、任務歷史 | 不讓背景裝飾降低按鈕可讀性。 |
| 第二層視窗 | 角色詳情、黑市交易、裝備、收藏、設定 | 大型列表與資產細節 | 開啟時不得遮擋 Windows 工作列。 |

## 5. 可及性與靜態備援驗收

1. 在只看灰階畫面時，可用、派遣中、可收取、鎖定與警示仍可由 icon／標籤辨識。
2. 關閉所有動態效果後，H1 與 H2 的可讀性和操作位置不變。
3. 在標準與緊湊配置下，24px 主功能 icon 與短標籤不重疊，任務倒數與收取按鈕未被裁切。
4. 在任務完成、背景解鎖、掛件解鎖同時發生時，H1 只顯示一個主行動，其餘收進佇列或角標。
5. 所有 `XL` 原創視覺尚未就緒時，文字＋Phosphor placeholder 仍可走完派遣、收取、地盤與收藏操作。
