# BGi Desktop：素材授權與導入決策方案

> 日期：2026-08-10（Asia/Taipei）
> 狀態：研究與決策文件。使用者已於 2026-08-10 選擇方案 M；未下載、導入、購買或修改任何 Godot 素材。
> 目的：為「高架線與霧金天際線」背景、前景掛件與 UI icon 建立可選的權利與導入路線。

## 1. 決策前提

- 對外發行的遊戲需要可追溯的素材權利來源、使用範圍、版本與授權文字。
- 第三方 UI icon、場景灰盒與最終原創插圖應分開決策與歸檔。
- 未列出單一資產頁的來源，仍需在取得當日重新核對其實際授權與價格；平台條款不會自動取代個別素材的授權。
- 此文件提供製作決策資訊，不構成法律意見。

## 4. 導入分級

### 可立即導入資格

以下是權利條件已足以進入「建立台帳 → 取得固定版本 → 保存 notice → 導入」流程的類別。此狀態不代表本文件已執行下載或導入。

| 類別 | 使用限制 | 導入前必備紀錄 |
| --- | --- | --- |
| Phosphor Icons（MIT） | 僅官方來源的功能性 UI icon；不使用品牌 logo 作產品識別。 | 版本、icon ID、來源 URL、MIT license 文字、notice 路徑、修改紀錄。 |
| Kenney（CC0） | 僅灰盒、構圖與交互驗證；不得當最終 BGi 視覺主資產。 | 資產頁 URL、版本、日期、內附 license、灰盒用途標記。 |

### 需使用者選擇

| 決策 | 原因 | 使用者需指定的最小資訊 |
| --- | --- | --- |
| 原創內製或委託 | 涉及預算、作者、交付時程、權利移轉與修改權。 | 作者／供應商、預算上限、是否要求完整權利移轉、可接受的交付格式。 |
| 付費資產庫 | 涉及購買支出與每個商品的風格適配、授權、帳號與發票保存。 | 商品 URL、預算上限、可否作暫用或最終資產。 |
| 個人創作者市集 | 必須逐項確認作者權利鏈與專案使用範圍。 | 候選 URL、授權條款、是否要求排他或客製。 |

### 不得導入

- Pinterest、搜尋圖片、未驗證社群貼圖、遊戲截圖、生成來源或作者不明的素材。
- 未附個別商用權利條款的市集素材。
- 含真實品牌、人物、幫派、地名或可交易貨幣標誌的素材。
- 直接將 Kenney 灰盒素材調色後當成最終「高架線與霧金天際線」背景或 BGi 專屬掛件。

## 5. 建議的導入方案

### 方案 M：MVP 最小風險

1. UI icon 採 Phosphor MIT，先覆蓋第 10 節列出的 10 個功能概念。
2. 場景與掛件維持文字／色塊暫代；若需要構圖驗證，只用 Kenney CC0 灰盒。
3. 完整背景、成品掛件與風格化 UI 由原創內製或委託完成後再替換。

適合現在的 QA 前核心功能開發：成本未被強加，權利邊界最清楚，正式美術不會阻塞完整循環驗證。

### 方案 P：付費套件加速原型

1. 保留 Phosphor 作功能 icon。
2. 選定一個具明確商用授權的付費套件，限用於暫用背景元件或非核心掛件。
3. 首張完整背景、產品識別與關鍵掛件仍採原創交付。

適合使用者確認套件 URL、價格與使用範圍後。此方案可縮短原型視覺空白期，但增加台帳與風格整合成本。

### 方案 O：原創優先

1. 先完成原創美術交付規格與委託條款。
2. UI icon 可使用 Phosphor，或在原創 icon 完成後替換。
3. 背景、前景掛件與主視覺全由原創作者交付。

適合預計較早展示或發行的版本；成本與時程需由使用者核定。

## 7. 已選定路線：M（最低風險 MVP）

使用者已選擇 `M`。目前只允許維護以下研究與候選資格：

1. Phosphor Icons：功能性 UI icon 的官方 MIT 候選。
2. Kenney：只作場景灰盒與構圖驗證的 CC0 候選。
3. 背景、前景掛件、角色、收藏、裝備與產品識別：維持文字／色塊暫代，等待使用者依實際遊戲內容提供素材方向，或另行要求生成與權利方案研究。

`M` 不授權下載、導入、購買或生成成品素材。當使用者提供單一素材 URL 或指定生成工具時，先對該來源或工具的當日商用條款、輸出權利、內容限制與台帳欄位進行獨立研究，再提出可核准的取得方案。
