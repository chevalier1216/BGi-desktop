# BGi Desktop：素材採用閘門與權利追溯研究

> 日期：2026-08-10（Asia/Taipei）
> 狀態：研究。只整理採用條件與台帳要求；未取得、下載、導入、購買任何素材，未修改 Godot 或 Git。
> 對象：高架線與霧金天際線背景、前景掛件、功能性 UI icon 與其動態／靜態備援。

## 1. 目的與採用原則

本文件補足既有授權決策文件的「採用前檢核」。來源具可商用條款只代表可進入審核，不代表可直接放入產品。

所有候選資產通過下列四項，才有資格被標示為「可導入」：

1. 權利可追溯：作者、官方來源 URL、取得日期、版本與授權全文可對應。
2. 使用範圍適配：可用於買斷桌面遊戲與日後 Steam 發行；修改、散布與必要 notice 條件明確。
3. 技術資料完整：靜態主圖／備援、獨立分層、檔案雜湊與尺寸資料均可交付。
4. 設計邊界相容：不含真實品牌、地名、組織、可交易貨幣標誌；動態只能提供視覺回饋，且不會綁定背景以外的掛件。

## 2. 採用閘門

| 閘門 | 決策者 | 必要證據 | 通過結果 | 失敗結果 |
| --- | --- | --- | --- | --- |
| G0：視覺範圍 | 使用者／設計 | 已核准主題、畫布與分層規格 | 可研究候選資產 | 保留為風格參考，不取得檔案 |
| G1：來源路線 | 使用者 | 選擇 `M`、`P` 或 `O`；付費路線另附預算上限 | 可建立該路線的候選清單 | 不下載、不購買、不聯絡作者 |
| G2：單一資產權利 | 美術／產品負責人 | 作者、商品／官方 URL、授權文字、商用／修改／散布條件、價格或合約 | 可登錄台帳，等待技術檢核 | 列為不可導入或需補證 |
| G3：交付完整性 | 美術／程式 | 資產 ID、版本、雜湊、尺寸、分層、靜態備援、效果插槽資料 | 可導入候選 | 不可導入；要求補交 |
| G4：產品驗收 | 程式／QA | 背景替換、掛件位置不變、靜態備援、減少動態與數值不變性測試 | 可納入版本候選 | 退回 G3；不以程式補救缺漏權利或素材 |

## 3. 來源路線的最小決策表

| 回覆 | 僅可進行的下一步 | 成本與商用風險 | 現階段不可做 |
| --- | --- | --- | --- |
| `M`：最低風險 MVP | 為 Phosphor UI icon 與 Kenney 灰盒建立候選台帳與版本清單 | Phosphor 為 MIT，需保留 notice；Kenney 資產頁為 CC0、可商用，惟灰盒風格不可作最終主視覺 | 不把 Kenney 轉為最終天際線／掛件；不取得任何檔案直到另有導入核准 |
| `P`：指定付費候選 | 使用者提供單一商品 URL、購買帳號與預算上限後，逐項核對授權與交付格式 | GameArt2D 的付費條款允許商用與修改，但禁止單獨轉售、分享、再授權或重散布；價格與商品適配須以當日商品頁為準 | 不採用「平台有上架」作權利保證；不自動購買 |
| `O`：原創優先 | 轉為作者 brief、合約條款與交付台帳欄位的審核 | 成本與交期未定；核心風險是未取得全球、永久、可修改、可用於發行平台的明確權利 | 不假設委託即取得完整著作權或排他權；不聯絡作者 |

## 5. 最小素材台帳欄位

以下欄位在 G2／G3 前必須完整；缺任一項則狀態為 `needs_choice` 或 `blocked`，不可標記為 `ready_to_import`。

| 欄位 | 說明 |
| --- | --- |
| `asset_id`、`asset_version`、`asset_type` | 穩定 ASCII 鍵值、版本與背景／掛件／icon 類別。 |
| `source_status` | `ready_to_import`、`needs_choice`、`blocked` 三者之一。 |
| `author`、`source_url`、`acquired_at` | 作者、官方／商品來源、實際取得日期。 |
| `license_name`、`license_url`、`commercial_allowed`、`modification_allowed` | 條款與商用／修改判定。 |
| `cost_currency`、`cost_amount`、`receipt_reference` | 原創委託或付費來源必填；免費來源填 `0` 並保留授權證據。 |
| `notice_requirement`、`notice_output_path` | 必須附帶的授權聲明及未來發行物的放置位置。 |
| `file_name`、`file_hash`、`canvas_size` | 實際交付檔的不可變追溯資訊。 |
| `layer_id`、`fallback_asset_id`、`effect_slot_ids` | 適用既有背景／掛件分層與動態規格。 |
| `rights_reviewed_by`、`reviewed_at` | 最後審核人與日期；不填即視為未審。 |

## 6. 禁止與待選清單

| 類別 | 狀態 | 原因 |
| --- | --- | --- |
| 搜尋圖片、Pinterest、未驗證社群貼圖、截圖 | `blocked` | 無法確認作者、授權與修改／散布範圍。 |
| 含真實品牌、地名、人物、組織、貨幣 logo 的素材 | `blocked` | 違反虛構世界與商標／權利邊界。 |
| Phosphor 官方功能 icon | `ready_to_import` 的資格 | 權利條款已驗證；仍待 G1 選擇與實際版本／notice 台帳。 |
| Kenney 官方遊戲素材 | `ready_to_import` 的資格，限灰盒 | CC0 商用條件已驗證；不得轉為最終主視覺或 BGi 識別。 |
| 原創背景、掛件、角色、收藏與裝備圖 | `needs_choice` | 等待作者、預算、權利條款與交付方式決定。 |
| 付費套件／市集作者 | `needs_choice` | 等待精確商品 URL、當日價格與個別授權核對。 |
