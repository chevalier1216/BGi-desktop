# BGi Desktop：視覺資產清單與美術方向提案（待核准）

> 日期：2026-08-10（Asia/Taipei）  
> 狀態：研究與提案；未核准。本文不授權下載、納入或修改任何成品美術、Godot 場景或程式。  
> 依據：已核准的「地盤＋探索」規格，以及現有透明、無框、工作列上方的 1280×260 Godot UI 骨架。

## 1. 推薦方向：**黑金桌上地盤模型**

以「深靛黑的桌面沙盤」為底，將虛構街區做成可逐段亮起的微縮地圖；功能面板像嵌入金屬邊框的情報夾，而不是寫實犯罪或真實地名。主視覺重點是地盤的燈光、標誌、收藏物與五名小弟的狀態變化。

這個方向符合低頻桌面常駐需求：遠看能辨識勢力是否運作，近看能閱讀任務與收藏；也避免把虛構黑市題材做成真實人物、幫派或交易的視覺再現。

### 風格板與設計 token

| 層級 | 建議 | 用途 |
| --- | --- | --- |
| 基底 | `#0C1018` 深靛黑、`#141C28` 石墨藍 | 透明視窗內的面板與沙盤陰影 |
| 框線 | `#B9934D` 霧金、`#5F4925` 暗銅 | 地盤邊界、選中狀態、稀有度框線 |
| 運作訊號 | `#5CCB8A` 可用、`#73A7FF` 派遣中、`#F1C75B` 待收取 | 五名同外觀小弟與任務狀態；不只靠顏色，另加形狀／動態 |
| 資源／危險提示 | `#C7746B` 警示、`#D7DDE7` 一般資訊 | 不用鮮紅作常態主色，保留給風險或鎖定狀態 |
| 字體 | Noto Sans TC（介面）、等寬數字字體（倒數與資源） | 繁中可讀性與數值穩定性 |
| 圖示語言 | 24px、2px 線條、圓角 2px；僅稀有度與收取使用低飽和填色 | 在 260px 高度維持可讀性，避免素材混雜 |

對一般文字，建議深色底與前景至少達 WCAG AA 4.5:1；金色僅作框線或大型標籤時也須另測對比，不能假設可讀。

## 2. 與現有桌面框架的視覺映射

| 現有區域 | 視覺目的 | 需盤點的素材類別 |
| --- | --- | --- |
| 左側「地盤／布置」 | 顯示區域、控制進度與布置入口 | 區域徽章、四段地盤狀態、據點／物件 icon、鎖定標記 |
| 中央「勢力場景」 | 低干擾的長期成長回饋 | 2D 沙盤底圖、街區輪廓、燈光覆蓋、收藏展示座、五名小弟 token |
| 右側「任務與收取」 | 1–3 分鐘內完成判斷、派遣與收取 | 任務類型 icon、倒數、隊伍槽、保底／額外報酬、刷新、收取、機率資訊 |
| 透明外圍 | 不攔截桌面操作 | 不放不可點擊的裝飾性圖像或浮動文字 |

## 3. 視覺資產清單（概念與製作規格，非採購清單）

| 類別 | 首版最小集合 | 顯示規格 | 設計限制 |
| --- | ---: | --- | --- |
| 小弟狀態 token | 1 造型 × 3 狀態 | 32px、可用／派遣中／待收取 | 五名初始角色外觀完全相同；以輪廓、徽記、脈衝環區分，不能只改色 |
| 地盤階段 | 4 | 96px 徽章＋沙盤覆蓋層 | 未涉足、已觸及、施加影響、已占據，且要在遠視距可辨識 |
| 任務類型 | 3 | 24px 單色／雙色 icon | 勢力、探索採集、地盤；不可使用真實貨幣、武器或犯罪教學符號 |
| 報酬標籤 | 6 | 16–20px icon＋短標籤 | 影響力、一般／高階分級貨幣標籤、收藏、材料、額外報酬；貨幣只作遊戲分級，禁止幣種 logo |
| 稀有度 | 5 | 邊框／角標 | 普通、精良、稀有、史詩、傳奇；色彩之外加邊框紋理／星級 |
| 收藏／環境物件 | 12 槽位的灰階輪廓 | 48px 卡片縮圖 | 首版先用「展示座」與類別輪廓，成品插圖待美術方向核准後製作 |
| 操作 icon | 10 | 24px | 地盤、布置、任務、收取、刷新、隊伍、人數、倒數、設定、收合 |
| 通知與狀態 | 6 | 16px | 鎖定、資訊、可收取、派遣中、完成、空狀態 |

## 6. 採用建議與核准點

建議先核准以下「授權方案 A」：

1. UI icon 以 Phosphor Icons 為唯一來源，採 `regular`／`duotone` 兩種重量；清單中的 10 個操作 icon 與 3 個任務 icon 先行指定。
2. Kenney 僅限場景灰盒與構圖驗證，不作最終黑金插圖；成品場景與收藏插圖採原創委製／內製，待另行核准預算、作者、權利移轉與交付格式後才製作。
3. 素材導入前建立 `THIRD_PARTY_ASSETS.md`：來源 URL、資產版本、檔案雜湊、下載日期、授權全文位置、修改紀錄、notice 輸出位置。
4. 優先做中央沙盤的「四段地盤覆蓋」與五名同造型小弟 token；兩者能直接驗證地盤成長與派遣狀態是否在桌面遠視距可讀。

尚待使用者核准：方向名稱、調色、icon 授權方案 A，以及「Kenney 僅灰盒、成品插圖改為原創」的界線。核准前，不新增素材檔、不下載、不修改 Godot。
