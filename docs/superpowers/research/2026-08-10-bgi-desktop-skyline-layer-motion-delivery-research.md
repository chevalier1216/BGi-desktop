# BGi Desktop：高架線與霧金天際線素材分層與動態效果交付研究

> 日期：2026-08-10（Asia/Taipei）
> 狀態：研究交付規格；僅根據已核准的背景收藏、前景掛件與動態相容性條文整理。
> 範圍：美術／程式間的素材邊界與驗收資料；不指定或取得任何第三方素材，不導入檔案，不修改 Godot。

## 1. 已確認的設計邊界

- 第一張完整背景為「高架線與霧金天際線」：是一張橫向連續的主題畫面，不是棋盤、格狀地圖或地盤數值載體。
- 地區進度可解鎖完整背景；取得時加入收藏庫，再以確認視窗決定是否套用。派遣與佔領數值留在選單。
- 前景掛件不屬於任何背景。背景切換不得改變掛件的擁有狀態、位置、前景層級或效果設定。
- 背景與掛件都可有多個動態效果插槽；每個插槽具效果類型、啟用、強度、速度與靜態備援。
- 所有動態均為裝飾性回饋，不能影響派遣資格、地盤進度、任務時間、掉落機率、收藏數量或任何報酬數值。

## 2. 畫面分層

美術交付以畫布相對座標為基準；程式只負責載入背景、保存掛件錨點與播放指定插槽，不可從圖像或效果反推遊戲數值。

| 顯示順序 | 層級 ID | 內容 | 背景切換行為 | 最小靜態備援 |
| ---: | --- | --- | --- | --- |
| 10 | `BG_SKYLINE_BASE` | 深靛天空、遠方建築剪影、霧金高架線、地面輪廓；完整可替換背景 | 整層替換 | 完整單張靜態背景 |
| 20 | `BG_SKYLINE_LIGHTS` | 背景內建的窗燈／高架線局部亮度區域 | 隨該背景替換 | 與 `BG_SKYLINE_BASE` 視覺相容的靜態亮燈版本或不亮版本 |
| 30 | `FG_HANGER_WORLD` | 可在畫布內自由拖放的裝飾性掛件：旗幟、招牌、吊牌、展示框 | 不替換、不重設位置 | 每一掛件的一張靜態正常外觀 |
| 40 | `FG_HANGER_FX` | 掛件自己的局部發光、漂浮、閃爍覆蓋 | 不替換、不重設效果參數 | 不發光、不漂浮的正常外觀 |
| 50 | `UI_SCENE_STATUS` | 小弟狀態、可收取提示等 UI 訊號 | 不由背景或掛件素材處理 | 現有 UI 的靜態可讀狀態 |

`BG_*` 與 `FG_HANGER_*` 必須分開交付、分開載入、分開驗收。背景不能含有「假掛件」來模擬已擁有物品；掛件也不得烘焙進完整背景。

### 掛件預設與自由拖放

- 每個掛件交付一組美術建議的 `default_anchor`，僅在玩家首次取得該掛件時套用。
- 玩家可在主題畫面畫布可用範圍內自由拖放掛件；不使用棋盤格、格點占位或背景專屬掛點作為限制。
- 玩家一旦移動掛件，保存其相對畫布座標作為該掛件的目前位置。背景替換、背景效果關閉或效果播放失敗均不得覆寫此座標。
- 畫布尺寸或桌面配置變更時，以相對畫布座標重新定位；若超出可見範圍，只可將掛件移回最近可見邊界，不可刪除、重置至預設位置或改變所有權。

## 3. 命名與交付清單

以下為交付命名規則，不代表要立刻建立這些檔案。`<id>` 為美術台帳分配的穩定識別碼，禁止只用中文名稱當程式鍵值。

| 類型 | 資產 ID 格式 | 範例 ID | 必交資料 |
| --- | --- | --- | --- |
| 完整背景 | `bg.<theme>.<variant>` | `bg.skyline_goldline.default` | 顯示名稱、畫布尺寸、靜態主圖、背景效果插槽清單、作者／權利來源 |
| 背景備援 | `bg.<theme>.<variant>.fallback` | `bg.skyline_goldline.default.fallback` | 對應背景 ID、靜態圖、可讀性檢查結果 |
| 掛件 | `hanger.<category>.<id>` | `hanger.sign.001` | 顯示名稱、靜態主圖、首次取得的預設錨點、可拖放範圍、前景層級、掛件效果插槽清單、作者／權利來源 |
| 掛件備援 | `hanger.<category>.<id>.fallback` | `hanger.sign.001.fallback` | 對應掛件 ID、靜態圖、與主圖相同外框／錨點 |
| 效果插槽 | `fx.<owner-id>.<effect>` | `fx.bg.skyline_goldline.default.rail_glow` | owner ID、類型、啟用、強度、速度、循環、靜態備援指向 |

每筆交付資料還須記錄：素材版本、檔案雜湊、授權／權利來源、可商用條件、可修改條件、修改紀錄與第三方 notice 位置。來源未驗證者不得進入此清單。

## 4. 動態效果插槽規格

| 欄位 | 型別／範圍 | 說明 |
| --- | --- | --- |
| `slot_id` | 穩定字串 | 依第 3 節格式命名；存檔與美術台帳以此對應。 |
| `owner_id` | 背景或掛件資產 ID | 插槽只屬於一個 owner；不得跨 owner 改寫。 |
| `effect_type` | 受控列舉 | `pulse_light`、`flicker_light`、`float_offset`、`mist_drift`、`static`。首版以這五種為界。 |
| `enabled` | 布林值 | 關閉時必須立即使用靜態備援，不隱藏資產。 |
| `intensity` | `0.0–1.0` | 僅調整視覺強度；`0` 等同不產生額外視覺效果。 |
| `speed` | `0.0–1.0` | 對應各效果的正規化速度；不得當作任務時計或遊戲節奏參數。 |
| `loop_mode` | `loop` 或 `once` | 背景與常駐掛件首版只允許 `loop`；`once` 保留給不影響狀態的入場裝飾。 |
| `fallback_asset_id` | 對應靜態資產 ID | 效果無法播放、使用者減少動態、資產缺漏時的正常外觀。 |
| `anchor` | 相對畫布座標 | 僅掛件使用；背景不得寫入或覆蓋此欄位。 |

## 5. 建議效果與循環

| Owner | 插槽 ID 範例 | 效果 | 循環建議 | 靜態備援 |
| --- | --- | --- | --- | --- |
| 天際線背景 | `fx.bg.skyline_goldline.default.window_pulse` | `pulse_light`：少量窗燈緩慢呼吸 | 5–8 秒無縫循環、不同樓棟錯相 | 固定 35–50% 亮度的窗燈 |
| 高架線背景 | `fx.bg.skyline_goldline.default.rail_glow` | `pulse_light`：霧金線條局部明暗 | 6–10 秒無縫循環 | 固定霧金線條，不使用全黑閃斷 |
| 天空背景 | `fx.bg.skyline_goldline.default.mist` | `mist_drift`：低對比霧層平移 | 18–30 秒無縫循環 | 無移動的半透明霧層 |
| 招牌掛件 | `fx.hanger.sign.001.neon_flicker` | `flicker_light`：短暫且低頻的招牌亮度變化 | 7–15 秒內最多一次變化；避免規律閃爍 | 正常固定亮度招牌 |
| 收藏掛件 | `fx.hanger.collectible.001.float` | `float_offset`：小幅上下漂浮 | 3–5 秒無縫循環，位移不超過掛件高度 3% | 原錨點的靜態收藏物 |

若系統提供「減少動態」偏好，所有插槽改為 `enabled=false` 並顯示既定 `fallback_asset_id`；不得改變收藏、地盤或任務資料。

## 6. 美術交付驗收

美術與程式共同以以下案例驗收：

1. 只載入 `BG_SKYLINE_BASE` 時，畫面已是完整、可讀的天際線主題畫面。
2. 關閉所有背景效果插槽後，背景仍完整可讀，沒有透明破洞或依賴閃爍才可辨識的元素。
3. 初次取得掛件時，套用其預設錨點；玩家拖放至三個不同位置後，切換至另一張背景，其 ID、相對畫布座標、層級與所有插槽設定完全相同。
4. 單一效果資產缺漏或無法播放時，只回退該 owner 的指定靜態外觀；其他背景、掛件、UI 與遊戲資料不受影響。
5. 將所有動態關閉後，任務倒數、派遣人數、地盤進度、報酬與收取結果在切換前後一致。
6. 在標準與緊湊桌面配置下，主背景不得覆蓋左右選單或把掛件推移到畫布外。
